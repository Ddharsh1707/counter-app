# Counter App

A counter with increase, decrease, reset and a custom step size.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/counter-app.git
```
